### 协作方式
如何成为协作者：[第九边缘发行计划](https://world.sch-nie.com/light_withme/key_part/)
{% endnote %}


{%note info%}
#### PART1：第九边缘：世界观续写
您需要在**时间线**上寻找一个合适的节点，并在此节点的相关背景下进行创作。
我们会保留您的署名，并将其加入到我们的**网页文件**当中。
即便这是很冒昧的，但我们可能会介入您的创作过程，以保证您的作品满足我们的基本要求。
{% endnote %}




{%note info%}
#### PART2：第九边缘：OC诞生故事
我们会为所有协作者、**部分同行者**献上此生唯一的礼物。
具体的情况，在[阴行世界：异世之篇](https://world.sch-nie.com/posts/27.html/)中有说明。
在创作完成后，我们会将文章的署名、修改、发布等权限转交给您。当然，您也可以在我们交付的稿件中，标记出您不满意、或您新添加的内容。
{% endnote %}
