# 全站视觉统一实施计划

**Goal:** 实现已确认设计，保留所有内容定制与阅读类型，统一视觉角色和明暗主题。

**Tech Stack:** Hexo 7.3、NexT 8.22、Stylus、Nunjucks、Cheerio、原生 JavaScript、Playwright。
**Spec:** `docs/superpowers/specs/2026-10-03-site-style-unification-design.md`
