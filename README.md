# 第九边缘：WORLD

第九边缘世界观网站的静态发布仓库，用于组织SCHNIE相关设定、故事与其他世界观内容。

[访问网站](http://world.sch-nie.com/) · [仓库分类导航](https://github.com/schrolemons)

## 仓库内容

本仓库保存Hexo生成的HTML页面与静态资源。

| 路径 | 内容 |
| --- | --- |
| `index.html` | 网站首页 |
| `SCHNIE/` | SCHNIE相关内容 |
| `menu/`、`about/` | 内容导航与网站介绍 |
| `posts/` | 文章页面 |
| `archives/`、`categories/`、`tags/` | 归档、分类与标签 |
| `css/`、`js/`、`images/`、`lib/` | 样式、脚本、图片与前端依赖资源 |
| `search.xml`、`atom.xml` | 搜索索引与订阅文件 |

仓库还包含按不同世界观或作品划分的页面目录，具体内容可从网站导航进入。

## 更新方式

设定、文章和主题的修改应在对应的Hexo源工程中完成，生成静态页面后再发布到本仓库。当前仓库根目录保存的是发布产物，不提供独立的Hexo构建配置。

重新发布时请保留本文件，或将本文件纳入源工程的发布产物，以便保留仓库说明。
